# Audio8Bit GUI — Windows

Русскоязычная графическая оболочка для [audio8bit](https://github.com/yumiaura/audio8bit).
Работает локально. Поддерживает режимы chords/lead/band/NES, распознавание из вокала
или инструментов, битность, частоту, транспонирование, настройку эффекта эхо,
аранжировки, дизеринга, кеширование Demucs и сохранение в WAV/MP3/OGG/FLAC.

## Запуск

1. Скачать **Audio8BitGUI-windows-x64.zip** на странице [Releases](https://github.com/mirivlad/audio8bit/releases).
2. Распаковать, при необходимости запустить `setup-prereqs.ps1` из PowerShell,
   либо самостоятельно установить Python 3.11 x64 и FFmpeg с ffprobe в PATH.
3. Запустить `Audio8BitGUI.exe` и нажать **«Установить/обновить движок»**. Для первой установки
   потребуется интернет и несколько гигабайт свободного места (Demucs/PyTorch/Basic Pitch).
4. Выбрать музыку, настройки и нажать **«Преобразовать в 8-bit»**.
5. Первый запуск движка скачает модель. Индикатор показывает активность, а не проценты.

Движок помещается в `%LOCALAPPDATA%\Audio8BitGUI\engine`; настройки — в
`%LOCALAPPDATA%\Audio8BitGUI\settings.json`.
Оболочка не содержит сторонний движок, модели ИИ, FFmpeg или PyTorch внутри EXE.

## Сборка

GitHub Actions → **Windows GUI** → Run workflow. Результат — artifact ZIP.
При изменениях в `main` workflow также создаёт GUI-релиз `gui-v0.2.0`.

Локальная сборка (Python 3.11 x64):

```powershell
python -m pip install "pyinstaller>=6.12,<7"
python -m PyInstaller --onefile --noconsole --name Audio8BitGUI --clean windows_gui/app.py
```

## Лицензия

Исходники **оболочки** в папке `windows_gui` под MIT — см. `windows_gui/LICENSE`.
Исходный audio8bit под **PolyForm Noncommercial 1.0.0**, а не OSI open-source.
Коммерческое использование движка требует отдельной лицензии автора. Лицензия
в корне репозитория относится к исходному движку.

## Если Basic Pitch не загружается

Откройте **«Проверить библиотеки»**: журнал покажет полный traceback и версии
Python-пакетов. **«Восстановить зависимости»** установит совместимую версию
setuptools (с `pkg_resources`), обновит `pretty_midi` и проверит импорт
Basic Pitch. Уже скачанные модели Hugging Face и исходные аудиофайлы не
удаляются. Предупреждения HF_TOKEN / symlinks / CoreML / ONNX не являются
сами по себе ошибками конвертации.

## Windows: ошибка UnicodeEncodeError / cp1251

В версии GUI 0.1.2 все дочерние процессы Python запускаются с
`PYTHONIOENCODING=utf-8:backslashreplace`, `PYTHONUTF8=1` и
`PYTHONUNBUFFERED=1`. Это предотвращает падение при выводе путей к
файлам с японскими, китайскими и другими символами, не кодируемыми в CP1251.
Движок переустанавливать не нужно. Если в старой версии конвертация
завершилась с ошибкой только на строке `print(f"Wrote {output}")`,
результирующий файл мог уже сохраниться на диск — проверьте папку.

## Новая аранжировка (0.2.0, движок 0.0.4)

GUI теперь содержит wheel **модифицированного движка из этого форка**, а не
устанавливает старый `audio8bit==0.0.3` из PyPI. Для перехода с прежней версии
нажмите **«Установить/обновить движок»**: Python-окружение и загруженные модели
останутся на месте. В статусной строке должна появиться версия `0.0.4`.

Изменения в режимах **NES** и **Чип-группа**: локальный выбор вокала/
инструментальной мелодии, отдельные инструментальные ноты для определения
аккордов, приоритет исходной басовой партии, сохранение переходов в ударных
вместо повторения одного бара, ритмический аккомпанемент и арпеджио,
согласованное с темпом. Алгоритм может анализировать две дорожки вместо одной,
поэтому первая обработка станет медленнее. Результат **не гарантирует**
качества ручной студийной аранжировки; это экспериментальный этап улучшений.
